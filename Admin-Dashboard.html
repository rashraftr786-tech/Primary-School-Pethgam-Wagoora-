🛡️ Operational Status

Firebase source: Shared firebase-config.js is used. No Firebase configuration is duplicated in this dashboard.
Live data: Sample/demo records have been removed. Counts and review lists are loaded from Firestore each time the dashboard is refreshed.
Open access: There is no login or Firebase Authentication gate in this file. The dashboard can only be fully functional when Firestore Rules explicitly permit the requested collections to be read/written without authentication.
