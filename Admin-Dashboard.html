🛡️ Security & Operational Notices

Admin account: The live dashboard must never treat preview/mock mode as proof of Firebase authorization.
Firestore Rules: Client-side checks are only convenience checks. Authorisation must be enforced in Firestore Rules and trusted backend functions.
Attendance: Browser geolocation and WebAuthn improve verification but should be combined with backend validation and audit logging.
Deployment: The earlier Teacher Dashboard 404 shown in testing is a separate deployment/path issue. The dashboard file must actually exist in the GitHub Pages project under the exact linked filename.
